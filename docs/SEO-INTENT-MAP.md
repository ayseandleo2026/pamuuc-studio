# Audience, keyword, prompt and intent map

**Status: hypothesis, not measurement.** The specification is explicit that a
qualitative map is "a strategic hypothesis, not a volume forecast" and that
volume, difficulty or priority must never be presented as measured unless
supported by current data. Nothing below has been checked against Search
Console, Keyword Planner or Trends, because this repository has no access to
them. Validate before commissioning any page.

## Rule applied

One accountable URL per intent. An intent is split only when the answer, the
evidence, the audience, the location or the conversion action genuinely
changes — not when the wording changes. Every row therefore names either a
live URL or an explicit gap.

## Long conversational prompts to carry real constraints

The specification asks for prompts with quantity, location, property type,
role mix, timing, durability and reorder needs attached. These belong in the
prompt library in `SEO-MEASUREMENT.md`, not in the keyword map, because they
are measured differently.

## What must be validated before any page is commissioned

1. Search Console queries already reaching the site, by country and language.
2. Keyword Planner and Trends for the four sector clusters.
3. Real language from sales conversations, proposals and form submissions.
4. Current search results for each intent — is one page enough, or does the
   result set show genuinely different answers?

## Sequencing

The specification's own recommendation: give the primary sectors depth before
adding secondary ones, and add languages only when demand, native quality and
proof are ready. English and Spanish first, French where hospitality and
wellness evidence supports it. The site already publishes five languages — the
question for German and Italian is now maintenance burden, not launch.
